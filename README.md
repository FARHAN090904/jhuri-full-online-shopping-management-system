## ⚙️ How to Run

1. Install requirements:

pip install -r requirements.txt

2. Run server:

python manage.py runserver

## ✨ Features

- User Registration & Login

- JWT Authentication

- Password Reset with OTP

- Product Listing & Search

- Shopping Cart

- Order Management

- Invoice PDF Generation
